# ميزان — نظام المحاسبة الداخلي

نظام محاسبة داخلي مجاني بالكامل، بيشتغل على **GitHub Pages**، وبيستخدم **Firebase** (الخطة المجانية) لتسجيل الدخول وقاعدة البيانات.

## المميزات

- **دخل ومصروفات وتحويلات** بين البوابات، مع رسوم البوابة اللي بتتحسب تلقائياً (نسبة % + مبلغ ثابت).
- **بوابات دفع غير محدودة** (Stripe، PayPal، تاب، Paymob، بنك، فودافون كاش، خزينة…). كل بوابة ليها رصيد وتحليلات خاصة بيها: الدخل، المصروفات اللي طلعت منها حسب التصنيف، الرسوم، والتحويلات.
- **لوحة مؤشرات (KPIs)**: الدخل، المصروفات، صافي الربح، هامش الربح، الرصيد النقدي، رسوم البوابات، معدل الصرف الشهري، المدة اللي يكفيها الرصيد، متوسط قيمة الدخل، وكل مؤشر مقارن بالفترة اللي قبله.
- **رسوم بيانية**: التدفق النقدي، توزيع المصروفات، تطور الرصيد، مقارنة البوابات، أعلى العملاء، وميزانيات التصنيفات.
- **الضرائب لكل بوابة**: تفعّل الضريبة على أي بوابة وتحدد نسبتها (مثلاً 15%) وطريقة حسابها: **المبلغ شامل الضريبة** (الضريبة = المبلغ − المبلغ ÷ 1.15) أو **الضريبة فوق المبلغ**. الدخل في المؤشرات بيتحسب من غير الضريبة، والضريبة بتتجمّع في صفحة **الضرائب والتصفية** على فترات (كل 15 يوم أو كل شهر أو كل ربع سنة). لما تدفعها اعمل **تصفية** للفترة، وهتتسجّل كحركة خارجة من البوابة اللي دفعت منها، ومش بتتحسب مصروف.
- **كشوفات حساب** لأي فترة، ولأي بوابة أو كل البوابات، بفلاتر حسب النوع والتصنيف والمستخدم، مع رصيد افتتاحي ورصيد متحرك. التصدير: **PDF / صورة PNG / Excel / CSV / طباعة**.
- **مستخدمين وصلاحيات**: أدوار جاهزة (مالك، مدير، محاسب، مدخل بيانات، مشاهد) أو صلاحيات مخصصة (12 صلاحية). الصلاحيات بتتطبق على السيرفر من خلال قواعد Firestore.
- **سجل نشاط كامل**: كل إضافة أو تعديل أو حذف بيتسجل باسم المستخدم ووقته، ومعاه الفرق بين القيمة القديمة والجديدة. السجل للإضافة بس، ومحدش يقدر يعدّله.
- **أكثر من شركة** في نفس الحساب، وكل شركة ليها عملتها وشعارها وعملات إضافية بأسعار صرف.
- استيراد معاملات من Excel/CSV، ونسخ احتياطي واسترجاع JSON، ووضع ليلي، وتصميم بيشتغل على الموبايل.

## التشغيل خلال ~15 دقيقة

### 1) إنشاء مشروع Firebase (مجاني)
1. ادخل على https://console.firebase.google.com واعمل **Add project**. تقدر تقفل Google Analytics.
2. من **Build → Authentication → Get started** فعّل **Email/Password**.
3. من **Build → Firestore Database → Create database** اختار **Production mode** واختار أقرب منطقة (مثلاً `europe-west` أو `me-central`).
4. من تبويب **Rules** امسح المحتوى والصق محتوى ملف `firestore.rules` كله، ودوس **Publish**.
5. من **Project settings (⚙️) → General → Your apps** دوس على أيقونة الويب `</>` وسجّل تطبيق جديد (من غير Hosting). هيظهرلك كود فيه `firebaseConfig`.

### 2) ربط السيستم بـ Firebase
افتح `js/config.js` والصق القيم:
```js
export const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "your-project.firebaseapp.com",
  projectId: "your-project",
  storageBucket: "your-project.appspot.com",
  messagingSenderId: "123...",
  appId: "1:123...:web:..."
};
```
> القيم دي مش سرية، وعادي تكون في كود عام. الحماية الحقيقية من قواعد Firestore.

### 3) النشر على GitHub Pages
1. اعمل Repository جديد على GitHub (ممكن يكون Private لو عندك GitHub Pro، أو Public).
2. ارفع كل الملفات (`index.html` و`css/` و`js/` و…) في الـ root.
3. من **Settings → Pages**: اختار **Deploy from a branch** → `main` / `root` → Save.
4. بعد دقيقة هيبقى اللينك: `https://USERNAME.github.io/REPO/`
5. **مهم:** ارجع لـ Firebase → **Authentication → Settings → Authorized domains** → **Add domain** → `USERNAME.github.io`

### 4) أول استخدام
1. افتح اللينك → **أنشئ حساب** → أنشئ شركتك (هتبقى أنت **المالك**).
2. من **بوابات الدفع** أضف بواباتك وحدد نسبة الرسوم لكل بوابة.
3. من **المستخدمين** ابعت دعوة لكل فرد في الفريق بإيميله واختار صلاحياته. هو يفتح اللينك، يسجّل بنفس الإيميل، ويقبل الدعوة.

## حدود الخطة المجانية (Firebase Spark)
50 ألف قراءة و20 ألف كتابة في اليوم، و1 جيجا تخزين. ده كافي جداً لفريق داخلي (عشرات الآلاف من المعاملات). السيستم بيفعّل الكاش المحلي عشان يقلل القراءات.

## الوضع التجريبي
لو `js/config.js` فاضي، السيستم بيشتغل في **وضع تجريبي** والبيانات بتتحفظ في المتصفح بس. مفيد للتجربة، ومن الإعدادات تقدر تحمّل بيانات تجريبية.

## هيكل الملفات
```
index.html            الصفحة الرئيسية
css/app.css           التصميم (RTL + وضع ليلي)
js/config.js          إعدادات Firebase
js/backend.js         طبقة البيانات (Firebase / تجريبي)
js/core.js            الصلاحيات، الحسابات، المؤشرات، سجل النشاط
js/ui.js              النوافذ، الرسوم البيانية، التصدير
js/pages/*.js         صفحات السيستم
firestore.rules       قواعد الأمان
```
